# Jayaveer Nallapati — Developer Portfolio

A clean, professional portfolio presenting Jayaveer’s software engineering,
full-stack, backend, and applied AI work.

## Highlights

- Responsive single-page portfolio
- Accessible light and dark theme toggle
- Theme preference saved locally and initialized from the system preference
- Project, experience, education, skills, recognition, and contact sections
- Semantic headings, keyboard-accessible navigation, and visible focus states
- Reduced-motion support

## Technology

The hosted application uses the supplied Vinext/React shell. Styling lives in
`public/css/portfolio.css`, while `public/js/theme.js` handles the theme toggle
without an animation or component dependency.
